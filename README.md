# orchestra-mcp/pack-native-gtk

GTK4 and Linux desktop plugin development agents

## Install

```bash
orchestra pack install github.com/orchestra-mcp/pack-native-gtk
```

Or via MCP:
```
install_pack(repo: "github.com/orchestra-mcp/pack-native-gtk")
```
